# Agents and Skills

This directory contains reusable agent workflow assets for the animation project.

本目录包含动画项目可复用的智能体工作流资产。

- `skills/animation-assistant`: Codex skill for building, improving, verifying, and operating interactive web animations.
  用于构建、改进、验证和运行交互式网页动画的 Codex skill。
- `skills/github-submit-assistant`: Codex skill for preparing GitHub update notes, disclaimer/source checks, validation, local commits, and pushes.
  用于准备 GitHub 更新说明、免责声明/来源检查、验证、本地提交和推送的 Codex skill。

PPT-related skills are intentionally not included in this repository.

PPT 相关 skill 有意不包含在本仓库中。
