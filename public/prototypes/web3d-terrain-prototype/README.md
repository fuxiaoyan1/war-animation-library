# Web 3D Terrain Prototype

This directory keeps only the source shell for the local Web 3D capability sample.

Generated outputs are intentionally ignored:

- `vendor/` is copied from `node_modules/maplibre-gl/dist` and `node_modules/three/build`.
- `tiles/` is generated by `tools/tactical-terrain-studio/generate-web3d-prototype-tiles.py`.

Prepare the local prototype with:

```bash
npm run prototype:web3d:prepare
```

The terrain is synthetic and exists only to test the MapLibre terrain + Three.js custom-layer path. It is not a historical reconstruction.
