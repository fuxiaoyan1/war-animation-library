# Source Website Index / 信息来源网站索引

This index lists the external websites currently recorded by the repository source logs under `docs/sources/*.md`. It is a website-level entry point for readers, reviewers, and downstream users. Page-level citations, attribution notes, uncertainty notes, and license caveats remain in the individual source files.

本索引列出当前 `docs/sources/*.md` 中已经记录的外部来源网站。这里是网站级入口，便于读者、审核者和二次使用者快速核查；逐条页面链接、署名说明、不确定性记录和许可风险仍以各动画或资产来源文档为准。

Important limits:

- Inclusion in this file does not imply affiliation, endorsement, sponsorship, accuracy guarantee, or a license grant from any linked website.
- Some entries are used only for cross-checking, visual reference, terrain/map technology, font delivery, audio attribution, or asset traceability.
- Media, map tiles, audio, fonts, and image-derived unit markers may carry separate terms. Read `NOTICE.md` and the relevant `docs/sources/*` file before reuse or redistribution.
