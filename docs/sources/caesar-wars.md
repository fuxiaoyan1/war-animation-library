# 凯撒大帝战争史资料来源

## 采用口径

- 动画聚焦公元前 58-44 年，从凯撒在高卢建立军功，到卢比孔引爆内战、击败庞培派各战区，最终在罗马遇刺。
- 战场、城市和路线坐标按现代地名近似定位，服务于态势线、镜头分段和叙事关系，不作为精密历史 GIS。
- 使用 `BCE-YYYY-MM-DD` 内部日期，避免浏览器负年份日期问题。
- 全片按 5 分钟播放设计；高卢战争与内战之间的长间歇压缩，防止时间轴出现空段。

## Notes

- 关键锚点：前 58 比布拉克特和孚日、前 57 萨比斯、前 55-54 不列颠远征、前 52 阿莱西亚、前 49 卢比孔和伊莱尔达、前 48 法萨卢斯、前 47 亚历山大里亚和泽拉、前 46 塔普苏斯、前 45 蒙达、前 44 三月十五日。
- 路线叙事分成两大阶段：高卢战争提供军队与政治声望，内战把这支军队带回罗马政治核心；法萨卢斯后仍需埃及、本都、北非和西班牙清场。
- 图标语义：古代陆战使用写实骑兵，海峡、亚得里亚、埃及和北非投送使用写实战船；图标保持水平，仅按路线左右方向镜像。
