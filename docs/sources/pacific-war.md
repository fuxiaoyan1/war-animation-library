# 日美太平洋战争战史资料来源

## 采用口径

- 动画聚焦 1941-1945 年日美太平洋主战场，按航母战、岛链推进和日本本土外围战压缩为 5 分钟。
- 太平洋跨日期变更线，地图坐标对夏威夷、中途岛等使用 0-360 经度表示，保证路线在同一太平洋视窗中连续。
- 用户指定后，本动画单位图标使用航空母舰 `carrier`，不复用普通战船。
