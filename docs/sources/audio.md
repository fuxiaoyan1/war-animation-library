## 配乐分配原则

- 战争系列中每部动画应优先使用不同背景配乐，避免所有影片听感同质化。
- 背景配乐必须是成品音频，不用本地合成替代；优先选择 44.1kHz、320kbps 或同等质量资源。
- 所有需要署名的曲目都必须在本文件和 README 中保留 `Track: ...` 与 `Music by ...` 信息。

## 战役音效

当前版本不再使用本地 Web Audio 自合成爆炸、俯冲或扫射声。战役节点音效全部来自成品音频文件，由 `src/lib/warScore.ts` 控制播放片段长度和音量。

音量平衡：背景进行曲设为 `0.72`；炮声 `0.34`、爆炸 `0.28`、飞机 `0.34`、扫射 `0.30`。原则是音效作为事件提示，不压过持续配乐。

时代匹配规则：古代战争不用爆炸、飞机或扫射音效，使用冷兵器/刀剑撞击声；拿破仑时代使用炮声；二战装甲/空地火力节点才使用炮声、爆炸、飞机和扫射组合。二战空战必须细分：`aircraft` 只给升空/接近，`airCombat` 给截击/追击并播放飞机+扫射，`bombing` 只给确有目标轰炸的节点并播放爆炸+飞机；预警、结果、返航收束节点保持静音。
