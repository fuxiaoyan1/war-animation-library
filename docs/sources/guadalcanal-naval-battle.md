# 第二次瓜岛海战资料口径

## 动画范围

- 时间范围：1942-11-14 22:30 至 1942-11-15 04:00。
- 空间范围：萨沃岛、铁底湾、瓜达尔卡纳尔北岸与亨德森机场外海。
- 动画目标：不是复原每艘驱逐舰的全部交火细节，而是突出三个研究节点：`South Dakota` 失电暴露、`Washington` 雷达火控射击、`Kirishima` 失能导致日军炮击机场任务失败。

## 主要来源

- National WWII Museum, `The Second Naval Battle of Guadalcanal`：<https://www.nationalww2museum.org/war/articles/second-naval-battle-guadalcanal>
- Naval History and Heritage Command, `Guadalcanal Campaign` 相关资料入口：<https://www.history.navy.mil/browse-by-topic/wars-conflicts-and-operations/world-war-ii/1942/guadalcanal.html>
- Naval History and Heritage Command infographic, `Guadalcanal Battleship Night Action`：<https://www.history.navy.mil/content/dam/nhhc/news-and-events/multimedia%20gallery/New%20Infographics/FINAL_PART3_Guadalcanal_BattleshipNightAction.pdf>

## 数据处理说明

- 地图坐标采用近似战术位置，服务于航向、相对位置和战术关系，而不是舰位级考证。
- 开场直接进入双方接近铁底湾的夜战航线，避免把搜索/航渡前奏拉成空镜。
- `cueEventIds` 只覆盖实际战斗节点：南达科他号失电暴露、华盛顿号雷达射击、雾岛号失能。撤退/战果确认节点保持静音。
