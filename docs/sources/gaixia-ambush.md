# 韩信十面埋伏：垓下之战动画资料

## 资料边界

本动画是战术地形示意，不是考古级复原。垓下位置采用安徽固镇濠城镇、霸王城/垓下遗址一带作为主口径，并记录灵璧北岸等说法的地望不确定性。地形层用今天淮北平原、沱河/古洨水、河汊低地与高地关系来还原战场约束。

## 主要事实来源

- 《史记·项羽本纪》：用于垓下被围、兵少食尽、四面楚歌和霸王别姬叙事。在线核对采用中国哲学书电子化计划：<https://ctext.org/text.pl?node=4890&if=gb&remap=gb&show=parallel>。
- 固镇县人民政府《垓下遗址》：用于垓下遗址位于固镇县城东、濠城镇北、沱河南岸，以及“霸王城”坐落在沱河边高地、沱河古为洨水等地望口径；该页还记录秦时固镇分属泗水郡、九江郡，汉高帝时分属沛郡、淮南国的行政沿革：<https://www.guzhen.gov.cn/zjgz/gzgk/gjjs/gxyz/>。
- 固镇县人民政府《垓下遗址简介》：用于垓下遗址与“四面楚歌”“十面埋伏”“霸王别姬”等历史文化叙事的地方文旅口径：<https://www.guzhen.gov.cn/zjgz/lswh/lsrw/81272724.html>。
- 固镇县人民政府《固镇县国土空间总体规划（2021—2035年）》：用于今日地形还原。该规划说明固镇为淮北平原南端，地表起伏小，受河水浸蚀形成河口较低、河岸较高、河间微凸的湖地/湾地/岗坡地结构，并记录沱河、浍河、澥河、怀洪新河等河湖水系：<https://www.guzhen.gov.cn/zfxxgk/public/50171/52065091.html>。
- Newton知识百科《垓下战役》参考图：用于对照“垓下之战示意图”“垓下之战作战图”和《武备志》五军阵图这类常见参考图的构图方式，已保存到 `public/assets/maps/source/gaixia-reference/`。这些图只作为战场态势/阵图参考，不直接作为动画底图，也不宣称精确复刻：<https://www.newton.com.tw/wiki/%E5%9E%93%E4%B8%8B%E6%88%B0%E5%BD%B9>。
- 美国陆军 terrain-analysis/OCOKA 口径：用于把地形层从“好看背景”提升为军事教学图层，重点标出 observation/fields of fire、cover and concealment、obstacles、key terrain、avenues of approach 对应的高地、河汊障碍、东口通道和杀伤区：<https://www.lineofdeparture.army.mil/Journals/Gray-Space/Archive/Summer-2025/Terrain-Analysis/>。
- NATO/APP-6、MIL-STD-2525 一类战术图形口径只作为视觉语法参照：用 K/AA/EA/BL 等短标签表达关键地形、接近路、杀伤区、封锁线，不把古代军队硬套现代编制符号，也不宣称采用正式军标全套规范。
- 地形可视化参考采用 shaded-relief/hillshade 的一般制图原则：高地要有受光面、背光侧壁、投影和等高线共同提示，路线与单位要贴在高程面上，而不是只把图标做成立体。

## 建模取舍

- 采用短时段小时级时间轴：从楚军傍晚退守垓下，到夜间四面楚歌，再到黎明合击和小股突围。
- 使用克制的矢量地形作战图风格，而非普通政区底图或 DEM 影像底图：底层直接绘制北岸岗脊、垓下东西岗、营垒缓坡、旧河汊低地、东口通道和阴陵追击道，配合河流、霸王城/楚军内营土垒和汉军外线合围区表现“十面埋伏”的地形约束。
- 2026-05-30 三维战术样板版把地形拆成 `terrainReliefSurfaces`：北岸弩阵高地、垓下东西岗、霸王城营垒台地、南侧河汊低地、东口诱隙通道、阴陵追击走廊都有 elevation/baseElevation、上表面、侧壁和投影。这里是战术教学地形，不是实测 DEM；高程数值用于表现“高地控制、低地障碍、通道诱歼”的相对关系。
- 2026-05-30 二次三维化版把高程差视觉放大为沙盘式阶面：每个地形面同时画 drop shadow、背墙、侧墙、底面、顶面、高光和边缘线，避免只在地图上写“42m”但视觉仍像平面图。
- 同版新增 `tacticalGraphics`：K1 北岸弩阵可控河岸、O1 旧河汊限制南撤、AA 东口突围通道、EA 东口弩骑杀伤区、BL 南口封锁线、EA 黎明合击切割区。EA/BL 等图层按战斗时间晚显，避免开场提前剧透后续战术意图。
- 同版新增 `fieldworks` 与 `formations`：工事层标出霸王城外土垒、楚军内营土垒、东西营门、旧河汊壕沟、汉军前出营线；阵型层标出楚中军步阵、楚骑东侧屏卫、楚南侧步阵、汉西路步阵、北岸弩阵、东口交叉弩网、东南伏骑阵和韩信中军。阵型随时间显示/退场，避免只有运动图标而缺少战术结构。
- 镜头从上一版的近景倍率退到约 `1.0-1.12`，可视作战区域更大；单位图标从 `scale(0.88)` 缩到 `scale(0.58)`，约为原来三分之二，让多单位、多路线、多阵型同时在场时仍能读清。
- 2026-05-30 三次三维化版继续把默认镜头退到约 `0.82-1.02`，让垓下核心区、东口、南侧低地和阴陵走廊同时进入战术视野。为实现这个远景，垓下专用相机允许最小 `scale=0.82`，不再被通用地图交互层夹到 `1.0`。十面闭合节点单独退到 `0.88` 并略向南取景，使东南伏骑、南路伏兵、东口反压和北岸弩阵同框可读。营寨/工事/阵型不再只靠文字位置：外土垒和内营土垒绘制角塔，东西营门绘制门柱，旧河汊壕沟绘制下陷肋线，汉军营线绘制帐篷，步阵绘制盾牌方阵块，弩阵绘制弩机符号，骑兵屏卫绘制楔形骑兵节点，伏击线绘制三角伏击标。文字降到辅助层，避免“原地复杂化”。
- 参考“成阵兵群”风格后，阵型层新增 `formation-rank-dot`、`formation-front-line`、`formation-rank-guide` 和 `formation-front-standard`：楚中军用 6x7 点阵表示成阵步卒，楚南阵和汉步阵用较小方阵，弩阵用双排射击线，骑兵屏卫和伏击线用弧阵/楔形点列；正面线、排面引导线和旗标用于说明朝向、纵深和指挥节点。点阵不是逐兵复原，而是战术教学中的阵型密度与朝向提示。
- 2026-05-30 四次三维化修正取消“大面积深色地形盖层”的做法：`gaixia-relief-layer` 不再使用整层阴影滤镜，地形高差改由每个地形面的浅色顶面、逐边 `gaixia-relief-edge-face` 立面、轻投影和坡面线表达。楚军营区、工事面和阵型面同步降透明度，保证营门、道路、壕沟、阵型点阵和文字不被暗色层压住。
- 2026-05-30 五次三维化修正把垓下专用地图从“俯视平面+局部阴影”改为统一的 `elevated-isometric` 沙盘投影：经纬度先投为战术平面，再按 `baseElevation/elevation` 折算为可视高度，所有地形面、河道、战术图形、阵型、路线和作战单位共享同一套倾斜/压缩/抬升坐标。底图不再用深色图层压暗细节，而是绘制沙盘台面、三侧立面、网格线和地形棱面，让“立体地图”成为底层坐标逻辑，而不只是图标或阴影效果。
- 2026-05-30 六次三维化修正加入地表材质层：西侧河岸草地、北岸岗坡草地、中央干燥沙地、南侧河汊低湿地、东口追击通道和霸王城踏实营地都作为 `gaixia-ground-material` 多边形投到同一沙盘坐标；河道改为河岸、水体、高光三层。这个层级参考战术教学视频里的“地形底图+兵群点阵”可读性，但仍保留本项目的地形高差和工事/阵型语法。
- 2026-05-30 七次降噪修正取消大面积半透明块：地表材质改为不透明纹理分区，历史区域只保留线框，地形抬升顶面不再铺半透明色，杀伤区/通道等战术图形只用线与虚线。高差只靠侧壁、边棱、坡面线和投影表达，避免多层透明面叠成脏色。
- 2026-05-30 八次纠偏放弃硬纸板式等距沙盘：垓下底图切换为 `topographic-relief` 连续地表，取消整张地图倾斜、压缩和台面侧壁；高差只保留几像素的地形浮雕线，避免河道、营寨和兵群被巨大的棕色立面切碎。后续视觉目标以参考视频那种“连续地形底图 + 清楚兵群点阵 + 轻微立体阴影”为准，而不是大块几何沙盘。
- 早期曾使用 Mapzen/Amazon `elevation-tiles-prod` Terrarium DEM 高程瓦片生成本地 hillshade；2026-05-27 后改为纯矢量地形层，避免底图噪声抢走注意力。淮北平原真实起伏较小，动画中的岗脊、缓坡、洼地和通道用于战术表达，不宣称为精确等高线图。
- 趋势线做成立体感：每条作战线带下投影、高光线和细虚线，表现伏击线从地形上收束。
- 作战单位不只图标立体：每条路线和单位会暴露 `data-ground-elevation`，路线阴影向地形背光侧偏移，单位有贴地投影和锚杆，表达“沿地形运动”，不是新场景里重新冒出。
- 2026-05-27 细化版把“十面”拆成多层战术动作：西路步兵、北岸弩兵、北西盾阵、东口弩网、东南骑兵、南路伏兵、中军指挥线、东口诱隙、楚骑试探、弩骑反推、楚营队列碎裂、黎明三面切割和追击截口。它表达冷兵器时代步兵固守、弩阵压制、骑兵截击与心理战叠加，不把战斗画成少数现代箭头。
- 2026-05-27 进一步细化版把楚军退入垓下后的动作改为“先成阵，后被压碎”：中军步卒收拢为营阵，东侧楚骑屏卫，南侧步阵守低地口。之后才进入西侧外推、汉军后退稳住、汉军再压回、东口诱隙牵出楚骑和弩骑反压。这样“队列碎裂”发生在楚歌与多线压迫之后，不再与前文退入后无阵势相冲突。
- 地图视窗与 SVG 战场画布同步加大：垓下专用地图采用 `1180x2816` 战场画布，约为原先 `1180x704` 的四倍高度，并用纵向展开的战术投影承载多部队行动。首屏不再把整张竖长战场用 `meet` 缩成窄图，而是用横屏 `slice` 战术视窗放大铺满舞台；2026-05-27 进一步收紧垓下底图投影，并按事件使用 `1.14` 到 `1.32` 的战术相机倍率，让首屏与各节点默认落在作战核心区，不需要先手动拖到战场。复位回到当前事件对应的战术视角。作战单位按路线开始后持续显示，除突围、追击、心理战声线或被明确压碎/离场的阶段外，不用忽隐忽现来制造节奏。
- 路线语义修正：已完成但仍作为战术背景的路线不再整组变灰，避免被误读为“单位被消灭”。保留路线只轻微降噪，单位若仍在可见窗口内保持彩色。战斗特效不再固定落在事件坐标，而是优先计算当前事件关联汉军与楚军可见单位的实时位置，把近战效果放在双方接触中点；这用于避免“有特效但附近没有单位”。
- 后续投入部队补来源：黎明北路合击从北岸弩阵续接，南路合击从南路伏兵续接，西路割裂从西路压回线续接，东南骑兵截断从伏骑线提前进入；阴陵追击和乌江追逼也从上一段截骑/追骑路线继续，不再从地图中段突然冒出。
- 2026-05-27 追逃关系修正：项羽主力退入路线在楚军营阵成形后隐藏单位，只保留路线作为入营历史，不再让旧行军队列停在高地上。夜间冲围受阻节点新增东口汉骑横截线，楚军前方必须有明确阻碍。乌江终局新增项羽小股继续退走线，汉骑追击线停在其后方，避免画成楚军原地等追兵或汉军前方已经没有项羽小股。
- 2026-05-27 南侧阵线交接修正：楚军南侧步阵在合围闭合后不再孤立停在旧河汊边，而是交接为“楚南侧步阵被压回”；同时新增“汉南路贴住楚南口”封锁线，让南路汉军压上后持续在场，与楚军回缩线形成前后对应。
- 视觉风格采用浅色军图纸面和克制地形线，不使用大黑背景；地图上直接绘制山脊、缓坡、洼地、河汊和通道，用地形要素而不是嘈杂底图突出“十面埋伏”的空间约束。
- 骑兵路线按通道行进：东侧骑兵、东南伏击、项羽突围和汉骑追击线沿东口通道、南侧低地、阴陵追击道折行，避免把骑兵画成随意穿越垓下岗脊。
- 东口诱隙、夜间冲围和黎明合击是动画化战术解释：用于说明楚军并非“无人阻拦地离场”，而是在多层封锁和预备队压迫中只剩小股骑兵突围。具体队列走位仍为示意，不宣称有逐队精确史料。
- 作战单元区分汉军步兵、骑兵、弩兵，楚军步骑与项羽主力；图标改为 PNG素材网古代中国士兵、步兵、骑兵和将军素材处理后的透明写实资产，不再使用抽象内联 SVG。素材授权未核实，仅用于本地私人演示。
- 四面楚歌节点用声波和民乐主题表现心理战，不用爆炸。
- 行政/地望层只保留“秦属泗水郡旧界”作为历史行政口径参考，不再把动画合围区误画成行政区划。
- “十面埋伏”在这里作为后世熟悉的文化标题和合围意象使用；具体路线为动画化战术示意，不宣称为考古级精确复原。
