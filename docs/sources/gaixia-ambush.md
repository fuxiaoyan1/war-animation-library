# 韩信十面埋伏：垓下之战动画资料

## 资料边界

本动画是战术地形示意，不是考古级复原。垓下位置采用安徽固镇濠城镇、霸王城/垓下遗址一带作为主口径，并记录灵璧北岸等说法的地望不确定性。地形层用今天淮北平原、沱河/古洨水、河汊低地与高地关系来还原战场约束。

## 主要事实来源

- 《史记·项羽本纪》：用于垓下被围、兵少食尽、四面楚歌和霸王别姬叙事。在线核对采用中国哲学书电子化计划：<https://ctext.org/text.pl?node=4890&if=gb&remap=gb&show=parallel>。
- 固镇县人民政府《垓下遗址》：用于垓下遗址位于固镇县城东、濠城镇北、沱河南岸，以及“霸王城”坐落在沱河边高地、沱河古为洨水等地望口径；该页还记录秦时固镇分属泗水郡、九江郡，汉高帝时分属沛郡、淮南国的行政沿革：<https://www.guzhen.gov.cn/zjgz/gzgk/gjjs/gxyz/>。
- 固镇县人民政府《垓下遗址简介》：用于垓下遗址与“四面楚歌”“十面埋伏”“霸王别姬”等历史文化叙事的地方文旅口径：<https://www.guzhen.gov.cn/zjgz/lswh/lsrw/81272724.html>。
- 固镇县人民政府《固镇县国土空间总体规划（2021—2035年）》：用于今日地形还原。该规划说明固镇为淮北平原南端，地表起伏小，受河水浸蚀形成河口较低、河岸较高、河间微凸的湖地/湾地/岗坡地结构，并记录沱河、浍河、澥河、怀洪新河等河湖水系：<https://www.guzhen.gov.cn/zfxxgk/public/50171/52065091.html>。
- Newton知识百科《垓下战役》参考图：用于对照“垓下之战示意图”“垓下之战作战图”和《武备志》五军阵图这类常见参考图的构图方式，已保存到 `public/assets/maps/source/gaixia-reference/`。这些图只作为战场态势/阵图参考，不直接作为动画底图，也不宣称精确复刻：<https://www.newton.com.tw/wiki/%E5%9E%93%E4%B8%8B%E6%88%B0%E5%BD%B9>。

## 建模取舍

- 采用短时段小时级时间轴：从楚军傍晚退守垓下，到夜间四面楚歌，再到黎明合击和小股突围。
- 使用克制的矢量地形作战图风格，而非普通政区底图或 DEM 影像底图：底层直接绘制北岸岗脊、垓下东西岗、营垒缓坡、旧河汊低地、东口通道和阴陵追击道，配合河流、霸王城/楚军内营土垒和汉军外线合围区表现“十面埋伏”的地形约束。
- 早期曾使用 Mapzen/Amazon `elevation-tiles-prod` Terrarium DEM 高程瓦片生成本地 hillshade；2026-05-27 后改为纯矢量地形层，避免底图噪声抢走注意力。淮北平原真实起伏较小，动画中的岗脊、缓坡、洼地和通道用于战术表达，不宣称为精确等高线图。
- 趋势线做成立体感：每条作战线带下投影、高光线和细虚线，表现伏击线从地形上收束。
- 2026-05-27 细化版把“十面”拆成多层战术动作：西路步兵、北岸弩兵、北西盾阵、东口弩网、东南骑兵、南路伏兵、中军指挥线、东口诱隙、楚骑试探、弩骑反推、楚营队列碎裂、黎明三面切割和追击截口。它表达冷兵器时代步兵固守、弩阵压制、骑兵截击与心理战叠加，不把战斗画成少数现代箭头。
- 2026-05-27 进一步细化版把楚军退入垓下后的动作改为“先成阵，后被压碎”：中军步卒收拢为营阵，东侧楚骑屏卫，南侧步阵守低地口。之后才进入西侧外推、汉军后退稳住、汉军再压回、东口诱隙牵出楚骑和弩骑反压。这样“队列碎裂”发生在楚歌与多线压迫之后，不再与前文退入后无阵势相冲突。
- 地图视窗与 SVG 战场画布同步加大：垓下专用地图采用 `1180x2816` 战场画布，约为原先 `1180x704` 的四倍高度，并用纵向展开的战术投影承载多部队行动。首屏不再把整张竖长战场用 `meet` 缩成窄图，而是用横屏 `slice` 战术视窗放大铺满舞台；2026-05-27 进一步收紧垓下底图投影，并按事件使用 `1.14` 到 `1.32` 的战术相机倍率，让首屏与各节点默认落在作战核心区，不需要先手动拖到战场。复位回到当前事件对应的战术视角。作战单位按路线开始后持续显示，除突围、追击、心理战声线或被明确压碎/离场的阶段外，不用忽隐忽现来制造节奏。
- 路线语义修正：已完成但仍作为战术背景的路线不再整组变灰，避免被误读为“单位被消灭”。保留路线只轻微降噪，单位若仍在可见窗口内保持彩色。战斗特效不再固定落在事件坐标，而是优先计算当前事件关联汉军与楚军可见单位的实时位置，把近战效果放在双方接触中点；这用于避免“有特效但附近没有单位”。
- 后续投入部队补来源：黎明北路合击从北岸弩阵续接，南路合击从南路伏兵续接，西路割裂从西路压回线续接，东南骑兵截断从伏骑线提前进入；阴陵追击和乌江追逼也从上一段截骑/追骑路线继续，不再从地图中段突然冒出。
- 2026-05-27 追逃关系修正：项羽主力退入路线在楚军营阵成形后隐藏单位，只保留路线作为入营历史，不再让旧行军队列停在高地上。夜间冲围受阻节点新增东口汉骑横截线，楚军前方必须有明确阻碍。乌江终局新增项羽小股继续退走线，汉骑追击线停在其后方，避免画成楚军原地等追兵或汉军前方已经没有项羽小股。
- 视觉风格采用浅色军图纸面和克制地形线，不使用大黑背景；地图上直接绘制山脊、缓坡、洼地、河汊和通道，用地形要素而不是嘈杂底图突出“十面埋伏”的空间约束。
- 骑兵路线按通道行进：东侧骑兵、东南伏击、项羽突围和汉骑追击线沿东口通道、南侧低地、阴陵追击道折行，避免把骑兵画成随意穿越垓下岗脊。
- 东口诱隙、夜间冲围和黎明合击是动画化战术解释：用于说明楚军并非“无人阻拦地离场”，而是在多层封锁和预备队压迫中只剩小股骑兵突围。具体队列走位仍为示意，不宣称有逐队精确史料。
- 作战单元区分汉军步兵、骑兵、弩兵，楚军步骑与项羽主力；图标改为 PNG素材网古代中国士兵、步兵、骑兵和将军素材处理后的透明写实资产，不再使用抽象内联 SVG。素材授权未核实，仅用于本地私人演示。
- 四面楚歌节点用声波和民乐主题表现心理战，不用爆炸。
- 行政/地望层只保留“秦属泗水郡旧界”作为历史行政口径参考，不再把动画合围区误画成行政区划。
- “十面埋伏”在这里作为后世熟悉的文化标题和合围意象使用；具体路线为动画化战术示意，不宣称为考古级精确复原。
