# 蒙古帝国征服史资料来源

## 采用口径

- 动画不是完整逐年史，而是按 1206-1279 的关键征服节点压缩为 5 分钟：草原统一、西夏/金、花剌子模、速不台西探、巴格达、南宋和崖山。
- 经纬度采用现代城市/战场近似坐标，用于战役态势可视化，不代表精确军队行军路线。
- 跨欧亚战争采用压缩时间轴，非作战空白不按真实日历比例播放。

- 1206 称汗、1215 中都、1220 撒马尔罕、1223 迦勒迦河、1258 巴格达、1273 襄阳、1276 临安、1279 崖山作为叙事锚点。
