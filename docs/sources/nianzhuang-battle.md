# 淮海战役：碾庄圩围歼战来源说明

## 范围校正

本动画表现的是淮海战役第一阶段黄百韬第七兵团在碾庄圩被围歼的战斗，不是第二阶段双堆集黄维第十二兵团战役。用户明确纠正为“黄百韬碾庄圩”，因此数据文件、标题、测试门禁均以碾庄圩为准。

## 主要来源

- 中国军网：《碾庄圩战斗：奠定淮海战役全面胜利的铺底之战》，2024-02-02，<https://www.81.cn/js_208592/16284032.html>
- 华夏经纬网：《碾庄战役》，2021-07-30，<https://www.huaxia.com/c/2021/07/30/673333.shtml>
- Berkshire Publishing: `Huaihai Campaign (1948-1949)`，<https://www.berkshirepublishing.com/ecph-china/2018/01/05/huaihai-campaign-1948-1949/>

## 已落入动画的时间锚点

- 1948-11-06T18:00：华野按中央军委方针向徐州东侧新安镇地区黄百韬兵团全线出击。
- 1948-11-07T06:00：黄百韬兵团撤离新安镇，向徐州方向收缩；华野急行追击。
- 1948-11-10T20:00：动画近似表现黄兵团被压入碾庄圩防御地域，华野合围形成。
- 1948-11-11T12:00：黄百韬在碾庄圩接到就地抵抗命令并固守待援；邱清泉、李弥兵团由徐州东援。
- 1948-11-13T06:00：动画新增外围试攻/相持节点，表现华野由运动追击仓促转攻坚后，在大兴庄、大宋庄、彭庄、鲁楼梁庄等村落水网阵地遇阻。具体村落攻防细节来自多种战史和回忆材料，坐标与先后关系按可视化近似处理。
- 1948-11-13T18:00：动画表现东援在大许家一线受阻；画面拆为第一阻援带迟滞、第二阻援带试突和华野侧翼反压三段，先头仍未到碾庄。
- 1948-11-14T20:00：粟裕在主攻纵队会议上强调加强对壕作业、隐藏接近、逐点争夺。
- 1948-11-15T02:00：碾庄周围枪炮暂静，华野开始大规模挖掘纵横壕沟。
- 1948-11-19T10:00：粟裕在周家寨华野司令部下达总攻碾庄圩令。
- 1948-11-19T21:15：动画近似表现总攻步兵夜间突击发起。10:00 节点只表现总攻令、炮火准备和突击集结，不提前让部队突入内圩。
- 1948-11-19T22:30：动画近似表现第一道围墙被突破，外圈师级防御阵地碎裂并退向第二道围墙。
- 1948-11-20T03:30：动画近似表现第二道围墙被突破，华野突入碾庄圩内圩；第二道围墙不再完整显示，而是拆成北段破碎、东段失守、南段割裂。
- 1948-11-20T05:30：动画以独立叙事节点强调黄兵团部、25军军部等内圩核心失守；先显示黄部残队由内圩向大院上、吴庄方向连续后撤，再进入尤家湖、小院上-吴庄、三里庄等据点逐步清剿。
- 1948-11-22T18:00：动画近似表现黄百韬残部向倪庄附近逃散并终局；公开材料常以11月22日下午4时总攻、黄昏前后大势已去、入夜战斗全面结束概述终局，动画用 18:00 作为黄昏收束点。军级“被歼地”和黄百韬自戕地点标注只在这一节点后显示，避免提前剧透。

## 战术单位口径

- 华野侧以“纵队”为基本战役战术单位：4纵、6纵、8纵、9纵、13纵分别承担北、东、南、西及东南等攻坚方向；特纵和炮兵以火力路线/效果表达，不单独作为步兵机动路线。
- 国民党军侧改为“师级守点”为核心可视化口径：黄兵团部居中，第25军、第44军、第64军、第100军残部等以师级单位固定在村落、水沟和内围阵地上，不沿防御圈旋转。
- “五个军部、十个整师”保留为战役规模口径；具体画面不把全部十个师硬塞进碾庄核心圈，而是把第一道村落防线、第二道围墙、内圩残部据点三层分开表达。
- 村落、水沟、地堡和壕沟是攻坚细节层。在大兴庄、大宋庄、彭庄、鲁楼梁庄、曹八楼、吴楼、娄庄、前板桥、徐井洼等节点承接“纵队推进到村落阵地”的过程。
- 基本可视化原则：华野纵队用于看清外层包围和突击方向，黄兵团师级单位用于看清守军具体布防，村落阵地用于看清为什么必须转入对壕近迫。

## 坐标与表现口径

坐标用于交互动画视窗和路线相对关系，属于可视化近似，不作为考古级精确战场测绘。核心约束是：

- 第七兵团从新安镇西撤到碾庄圩，随后接为碾庄防御圈，不能凭空出现。
- 徐州东援从徐州出发，止于大许家/先头受阻位置；表现上必须有第一阻援带、第二阻援带和反压回线，不能让邱李兵团看起来已经突破阻援线并抵达碾庄。
- 华野追击、合围、阻援、对壕、总攻和追击倪庄必须有连续来源路线；解放军单位若设置 `unitVisibleUntil`，必须在该时刻前已经由同方向后续路线或包围/阻援代表线接手。
- 战斗效果绑定双方当前路线或单位附近，不在无单位位置爆炸。
- 单位除终局被歼灭或明确交接外，不用突然消失表达阶段变化。旧路线可按阶段退场，但退场前必须有可见单位或轨迹接续。
- 播放轴不按日历均分，但总攻段不能吞掉全片：以 1948-11-19T10:00 总攻令/准备为起点，总攻及后续收束约占整片二分之一；追击、合围、固守、试攻、对壕仍保留足够观看时间。组件和测试都必须使用同一套 `timelineGapOverrides`、`timelineActiveSpans`、`timelineDateAnchors`，避免拖动时间轴时看到瞬移或旧节奏。
- 碾庄圩攻坚必须有双方拉锯，而不是单向阶段切换：外围村落显示黄军反扑、华野壕线后撤稳住、再压回；夜间破口显示守军短促反扑和华野再压回；残点清剿显示北侧/南侧残部外突和华野反压回。
- 国民党军同样必须连续交接：第一道碎裂线接到第二道/内圩，内圩接到东侧据点，东侧据点再接到 22日16:00 后的 25军、64军、44/100军终局路线；18:00 后才显示对应“被歼地”。
- 地图文字不能提前剧透结局：合围、攻坚、清剿阶段只使用“据点、封锁点、阵地、破口、失守”等当前态文字；“被歼地、终局点”等结果性文字只在 1948-11-22T18:00 后显示。
- 地图画布采用 `4800x2880`，相机窗口按阶段收紧到徐州东援、碾庄核心或终局内圩。图标不能小到看不清，也不能大到遮住几十万人级战役的多路线关系；完成旧路线按阶段退场，避免把追击、合围、试攻、总攻和清剿全部叠在同一画面。
- 黄兵团师级布防单位使用固定坐标和固定朝向，避免防御阶段像“走马灯”一样沿圈旋转。
- 华野外层包围圈必须位于黄兵团第一道防线之外；试攻、对壕和总攻路线从外层来源线进入，不能先跑进黄兵团阵地内部再发生战斗。
- 第一道围墙突破后，外圈师级单位停止显示为完整守点；画面改为“外圈阵地碎裂退向第二道围墙”。第二道围墙突破后，先显示二道围墙破碎和内圩核心据点，再切换为残部东撤。
- 03:30 到 05:30 是第二道围墙突破后的内圩核心攻坚窗口；05:30 到 21日08:00 是内圩核心失守后的残部东撤窗口；21日以后不再把兵团部核心长期画成完整据点，而是转为东侧村落据点、华野多向清剿和徐东阻援并行。
- 1948-11-22T18:00 后，地图用晚显标注演示第25军、第64军、44/100军残部、兵团部终局点和黄百韬自戕地点；这些标注是军级残部终局的可视化近似，不作为精确测绘点。
- 地图文字比上一轮再放大一倍；因为战役单位密集，相机窗口同时略放宽，保证字号提高后仍能看清多方向压缩关系。

## 3D 地图重制口径

本轮重制把碾庄从二维 SVG 底图迁到 MapLibre + 本地 Terrarium DEM 地形层，但可见底图仍是绘制型历史战术图。现代卫星图、现代道路图只允许作为绘制参考信息，不能直接作为战争动画可见底图。

- 地形数据缓存到 `public/assets/maps/nianzhuang-real-terrain/terrarium/`，用于 `raster-dem` 和 `setTerrain`。组件暴露 `data-modern-imagery-visible="false"`、`data-visible-basemap="drawn-historical-tactical-terrain"`，避免后续误把现代影像贴回画面。
- 2026-06-01 追击幕修正：DEM 缓存和 3D 相机边界东扩到新安镇、东线/北线追击入场区，追击幕相机中心改由黄兵团西撤纵队与华野三路追击当前兵牌位置实时计算；运河桥渡、碾庄方向只作为上下文点保留。不能再让早期作战单位先在地形边界外运动，等镜头进入碾庄才突然出现。
- 2026-06-01 镜头/黑块修正：碾庄 MapLibre 相机改为固定阶段战术总览 zoom，实测关键节点约 10.31-10.71，避免再次贴脸；大面积地形 feature 的 overlay 阴影取消深色填充和 blur，只保留浅描边/轻墙面，防止全局视角下形成大黑块。回归测试必须同时检查 zoom 上限、相邻跳变和大尺寸深色 overlay。
- 战术图层、河渠、历史区域、地形区、工事、阵型、路线、事件点和被歼地标注全部在同一 MapLibre 投影下绘制。不得再出现“底层地图一套、战术图一套”的错层。
- 透明 SVG 只用于拖拽、缩放、测试读取相机状态；可见地图与战术内容由 3D 地形容器和 MapLibre 投影 overlay 承担。测试中 `.battle-map` 应保持透明，避免遮住地形。
- 带固定 `coordinates` 的作战单位必须按地图坐标投影后落位，不能挂在路线当前 marker 上。徐东阻援这类阵位单位尤其要贴着邱李兵团前锋，形成正面接触。
- 地形 feature 与工事线都必须暴露可高亮锚点，路线 `positionAnchor` 指向的工事/破口/壕线应在该路线活动时亮起，证明路线真的使用了阵地和工事。
- 单位图标在碾庄缩小到约 0.86，立体兵牌缩到约 0.68，避免村落水网、内圩和残点阶段挤成一团。
- 相机阶段保留 `data-focus-from`、`data-focus-transition-ratio` 等连续过渡元数据，追击、合围、阻援、总攻、清剿之间不能用硬切替代一镜到底。
- 第二道东段破口从 1948-11-19T22:30 起作为受压破碎锚点显示，后续 03:30 再进入失守/内圩突破叙事；路线和阵地显隐窗口必须互相匹配。
