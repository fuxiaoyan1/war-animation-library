# 战争动画藏书馆更新说明

更新时间：2026-06-06

对比基准：GitHub 远端 `origin/main` 的 `fd3a660a`。本地提交前基准为 `66eb1b3e`，本地相对远端已有 30 个未推送提交。本次说明聚焦用户特别要求的两部动画：`韩信十面埋伏：垓下之战` 与 `淮海战役：碾庄圩围歼战`。

## 总体变化

- 两部动画都从早期 SVG/概念战术图升级为真实地形与战术覆盖叠加的 3D 地图视图。
- 新增本地常驻预览发布脚本与 LaunchAgent 工作流，便于固定访问 `http://127.0.0.1:5177/`。
- 扩展 Playwright 门禁：不仅验证页面加载，还验证路线时间窗、单位可见性、特效绑定、镜头焦点、地图交互、三维底图和关键战术关系。
- 新增或补充大量本地地图瓦片、真实地形瓦片、影像瓦片和专用战术叠加层。
- 新增根目录 `DISCLAIMER.md`，并在 README/NOTICE 中显著链接，声明项目的历史资料、版权、非商业意图和反战立场。
- 新增仓库内 `github-submit-assistant` skill，用于后续每次 GitHub 更新前自动检查免责声明、来源说明、更新说明、验证、提交和推送事项。

## 韩信十面埋伏：垓下之战

### 相对 GitHub 远端的主要更新

- 从概念化包围图升级为真实 GIS/MapLibre 三维地形底图，加入本地缓存的高分辨率影像瓦片和 Terrarium 高程瓦片。
- 新增 `GaixiaTerrain3D` 战术覆盖层，把地形、河流、营垒、阵形、路线、单位、事件点和特效统一投射到真实地形地图上。
- 补出垓下战场的关键地形与人工构筑：沱河/古洨水、壕沟旧河汊、北岸岗地、西岗、东岗、南侧洼地、东口诱隙、阴陵追击道、霸王城外土垒、楚军内营土垒、西营门、东口营门、汉军前出营线。
- 楚军不再一开始就碎裂，而是先退入垓下并成阵：中军步阵、东侧骑兵屏卫、南侧步阵。
- 汉军合围不再是静态圆圈，而是西路步兵、北岸弩兵、北西盾阵、东口弩网、东南伏骑、南路伏兵、中军指挥线分层展开。
- 增加阵前拉扯：楚军西侧外推、汉军后退稳住、汉军重新压回。
- 增加东口诱隙链条：汉骑假退、楚骑试探、汉弩骑反压、夜间楚骑冲围受阻。
- 细化四面楚歌阶段：音乐声线、夜间冲围受阻、营内队列碎裂、霸王别姬与战术崩溃衔接。
- 根据用户反馈重调第 10 至 13 小时镜头：新增近距离 encirclement camera stage，让战斗面居中，减少画面给出大块空地。
- 根据用户反馈补强第 13、14 小时黎明突破营地的战斗场景：新增楚军内营后卫短拒、楚南口残阵拒止、楚东口骑卒护退三条路线，使汉军突破楚营时必须先看到楚军阻击和近战接触。
- 近战特效从固定事件点改为绑定可见汉楚单位的实时接触点；黎明合击支持多处接触特效，并优先绑定楚军阻击线，而不是只绑定项羽小股突围线。
- 项羽突围和后续追击不再像自由离场：保留东口护退骑卒、项羽小股东南突围、阴陵追骑、东城快战、乌江方向终局的追逃链条。
- 单位图标、路线和阵形连续性增强：完成路线保留彩色战术记忆，未交接或未消灭单位不提前消失。

### 垓下新增/强化的回归门禁

- 三维真实地形层必须渲染，MapLibre 战术覆盖层必须存在。
- 当前事件的单位必须位于地图核心区，不能靠在视窗顶部或被大面积空地挤出中心。
- 四面楚歌、霸王别姬、黎明合击等近景阶段必须保持约 2 倍战术放大，并在追击阶段恢复更广的追逃视角。
- 黎明合击事件必须显式包含楚军内营后卫、南口残阵、东口护退骑卒。
- 黎明合击必须显示多个楚军阻击单位和至少三处路线绑定近战特效。
- 主近战特效不能被项羽小股突围线抢占；突破楚营必须先表现阻击与近战。
- 夜间冲围、南口封锁、东口反压、项羽追逃等关键路线必须有来源路线和自然交接。

## 淮海战役：碾庄圩围歼战

### 相对 GitHub 远端的主要更新

- 从平面战术图升级为 `NianzhuangTerrain3D` 真实地形/影像底图，加入本地缓存地形与影像瓦片，叠加战术路线、阵地、村落、水网、道路和铁路。
- 战场范围扩大并重新组织镜头：新安镇撤退、碾庄圩核心、大许家阻援、徐州东援、外围村落试攻、对壕近迫、总攻突破、倪庄终局分别进入合适的相机阶段。
- 地图不再只是一个防御圈，而是分层表现江淮平原、水网、村落、壕沟、铁路/公路轴线、徐东阻援线、黄百韬第七兵团防御区。
- 重新梳理黄百韬兵团从新安镇撤退到碾庄圩固守的来源路线，避免守军突然出现在核心阵地。
- 徐州东援线从徐州方向出发，明确停在大许家/受阻区域，不穿透阻援线进入碾庄。
- 华野阻援、外层包围、各纵队攻坚、炮兵准备、对壕推进、总攻突破、清剿残点、倪庄终局都有连续路线和单位交接。
- 黄兵团防御从单一大圈细化为第一道村落防线、第二道内围防线、最后内核，并用第 25、第 44、第 63、第 64、第 100 军和黄百韬兵团部等标签表达防御组成。
- 增补 1948-11-13 前后外围试攻/相持段，包括多个村落节点，避免动画从固守待援直接跳到 11月19日总攻。
- 强化总攻后的残部关系：第一道防线破裂、第二道防线破裂、最后内核压缩、东/北/南方向残部回缩与华野清剿路线有明确接触。
- 修复多个镜头问题：减少硬切，避免相机焦点把战斗丢出主视区，压缩后期空白，保持终局残点清剿在可读区域。
- 修复单位连续性：黄兵团固定防御单位、残部回缩、华野攻坚/清剿单位、徐州东援单位按时间显示或隐藏，不再无因消失或残留在错误阶段。
- 调整单位/阵形视觉：去除容易误读的头点/密集圆点，增加更清晰的队列、标签和方向表达。

### 碾庄新增/强化的回归门禁

- 碾庄时间轴必须覆盖 1948-11-06T18:00 至 1948-11-22T20:00。
- 徐州东援必须被阻止在碾庄以西，不得穿过阻援线。
- 11月13日前后的外围试攻与相持必须存在，不能直接跳到总攻。
- 对壕近迫必须从 1948-11-15 后出现。
- 总攻、第一道防线突破、第二道防线突破、最后内核和黄百韬终局必须有明确时间锚点。
- 第一、第二、最后内核防线按阶段显示/隐藏，旧完整防线不得在突破后继续误导。
- 各阶段镜头必须聚焦当前作战面，不能用大面积空地挤压战斗场景。
- 残点清剿阶段必须显示东、北、南方向残部与华野清剿单位的接触，不允许把最终阶段画成单线推进。
- 三维地图、地形层、战术覆盖层、单位可读尺寸、路线可见性和特效绑定都有 Playwright 覆盖。
